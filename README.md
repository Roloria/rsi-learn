# RSI 学习站 · 递归自我改进

一个介绍、学习并**实验** AI RSI（Recursive Self-Improvement，递归自我改进）的网站。
长期目标：基于实验场的验证，沉淀出一个自改进 Agent 的底层架构。

## 实验场：它真的在跑一个 RSI 回路

选一个模板（产品策略改进 / 课件优化 / 难题求解），写下你的目标，然后观察
**生成变异 → 评估 → 选择 → 整合** 的循环把方案一轮轮推高：

- **变异算子**：新增 / 强化 / 剪枝 / 整合（组合拳）/ 满员替换
- **评估器含噪声**：观测分 = 真实质量 + 高斯噪声；噪声 σ 随轮次指数下降
  （评估器在改进自己的眼睛——元级递归）
- **反思事件**：连续 3 轮停滞触发大变异，跳出局部最优
- **经验库**：显著有效的变异沉淀为可复用模式（跨实验复利的雏形）
- **持久化**：实验全部保存在浏览器 localStorage，可回看 / 重跑 / 删除

引擎实现见 `src/lib/engine.ts`（爬山进化搜索，无任何后端依赖）。

## 开发

```bash
npm install
npm run dev       # 开发服务器
npm run build     # 产物输出到 dist/
npm run preview   # 本地预览构建产物
```

技术栈：Vite + React 18 + TypeScript + Tailwind CSS v4 + react-router（HashRouter）。
